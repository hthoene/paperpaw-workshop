| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[widgets] note.text` | Note | text | `` | What the note says, e.g. where to return the device if found. |
| `[widgets] note.heading` | Heading | text | `` | A small line above the note, e.g. If found. |
| `[widgets] note.face` | Font | `widgets.face.ui`, `widgets.face.book`, `widgets.face.italic` | `widgets.face.ui` | The font the text is written in. |
| `[widgets] note.size` | Size | `core.size.small`, `core.size.medium`, `core.size.large`, `core.size.fit` | `core.size.fit` | How large the widget's text is. Where it does not fit, it is made smaller. |
| `[widgets] note.align` | Alignment | `core.align.left`, `core.align.center`, `core.align.right` | `core.align.center` | Where the widget's text sits in its place: at the left, in the middle or at the right. |
| `[widgets] note.frame` | Frame | `core.frame.none`, `core.frame.line`, `core.frame.card`, `core.frame.dark` | `core.frame.none` | What the widget is drawn in; a dark card has light text. |
| `[widgets] note.padding` | Spacing | `core.padding.auto`, `core.padding.none`, `core.padding.small`, `core.padding.normal`, `core.padding.large` | `core.padding.auto` | Space between the widget's content and its edges or frame. |
| `[widgets] note.paper` | Colours | `core.plate.normal`, `core.plate.inverted`, `core.plate.light-gray`, `core.plate.dark-gray`, `core.plate.none` | `core.plate.normal` | Normal, inverted, a gray or transparent. Over a dark picture, pick light text. |
| `[widgets] note.ink` | Text | `core.ink.auto`, `core.tone.black`, `core.tone.white` | `core.ink.auto` | The colour of the widget's text; automatic is black or white, whichever reads. |
| `[widgets] note.corners` | Corners | `core.corners.auto`, `core.corners.square`, `core.corners.small`, `core.corners.round`, `core.corners.soft` | `core.corners.auto` | How round the widget's corners are; automatic follows the rest of the interface. |
| `[widgets] note.frame-line` | Frame line | `core.lines.auto`, `core.lines.thin`, `core.lines.medium`, `core.lines.thick` | `core.lines.auto` | How thick the line of the widget's frame is; automatic follows the interface's lines. |
| `[widgets] note.drop-shadow` | Shadow | `core.shadow.none`, `core.shadow.hard` | `core.shadow.none` | A solid shadow below and to the right of the widget's card or colour. |
| `[widgets] note.font` | Font | `core.widgets.font.all`, `core.widgets.font.menus`, `core.widgets.font.book`, `PaperPaw Sans` | `core.widgets.font.all` | The font of this widget. Text too large for a font from the card stays in the menus' font. |
