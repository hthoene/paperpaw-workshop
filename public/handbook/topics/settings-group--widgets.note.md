| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[widgets] note.text` | Note | text | `` | What the note says, e.g. where to return the device if found. |
| `[widgets] note.heading` | Heading | text | `` | A small line above the note, e.g. If found. |
| `[widgets] note.face` | Font | `widgets.face.ui`, `widgets.face.book`, `widgets.face.italic` | `widgets.face.ui` | The font the text is written in. |
| `[widgets] note.size` | Size | `core.size.small`, `core.size.medium`, `core.size.large`, `core.size.fit` | `core.size.fit` | How large the widget's text is. Where it does not fit, it is made smaller. |
| `[widgets] note.align` | Alignment | `core.align.left`, `core.align.center`, `core.align.right` | `core.align.center` | Where the widget's text sits in its place: at the left, in the middle or at the right. |
| `[widgets] note.frame` | Frame | `core.frame.none`, `core.frame.line`, `core.frame.card`, `core.frame.dark` | `core.frame.none` | What the widget is drawn in; a dark card has light text. |
| `[widgets] note.padding` | Spacing | `core.padding.auto`, `core.padding.none`, `core.padding.small`, `core.padding.normal`, `core.padding.large` | `core.padding.auto` | Space between the widget's content and its edges or frame. |
