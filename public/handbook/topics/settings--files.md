| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[files] archive` | Archive folder | text | `books/Archive` | Where “Move to the archive” puts finished books. |
| `[files] view` | Show books as | `files.view.list`, `files.view.covers` | `files.view.list` | A list with covers and how far each book is read, or a grid of large covers. |
| `[files] sort` | Order of books | `files.sort.recent`, `files.sort.name` | `files.sort.recent` | How the library sorts books: those read last first, or by title. |
