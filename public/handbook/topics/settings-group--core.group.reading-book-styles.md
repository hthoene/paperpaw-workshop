| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[core] publisher-styles` | Publisher's formatting | `true`, `false` | `true` | Use the book's own layout; off shows the text plainly. |
| `[core] book-align` | Book's alignment | `true`, `false` | `true` | Centred and right-aligned text as the book sets it. |
| `[core] book-indent` | Book's indents | `true`, `false` | `true` | First-line and hanging indents as the book sets them. |
| `[core] book-sizes` | Book's text sizes | `true`, `false` | `true` | Larger and smaller text as the book sets it. |
| `[core] book-spacing` | Book's spacing | `true`, `false` | `true` | Space around paragraphs as the book sets it. |
| `[core] book-fonts` | Book's fonts | `true`, `false` | `true` | Fonts the book brings, where the device shows them. |
| `[core] book-margins` | Book's margins | `true`, `false` | `true` | Quotes, poems and lists set in as the book sets them. |
| `[core] book-line-height` | Book's line spacing | `true`, `false` | `false` | The book's line spacing in place of yours. |
