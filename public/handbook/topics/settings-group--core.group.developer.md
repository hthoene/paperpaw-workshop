| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[battery] by-plugin` | Battery: what each plugin took | `true`, `false` | `true` | The battery's page also lists the plugins that were shown longest and kept the processor busiest this time awake. |
| `[fonts-browser] catalog` | Font library | text | `https://paperpaw.org/api/v1/fonts.json` | Where the list of fonts to download comes from: the address of a fonts.json. |
| `[store] catalog` | Plugin library | text | `https://paperpaw.org/api/v1/plugins.json` | Where the list of plugins to install comes from: the address of a plugins.json. |
| `[update] server` | Update server | text | `https://paperpaw.org` | Where PaperPaw asks for updates online: the address of a server with PaperPaw's update service, paperpaw.org unless you run your own. |
