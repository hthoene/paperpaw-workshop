| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[battery] by-plugin` | Battery by plugin | `true`, `false` | `true` | Also lists the plugins that did the most since waking. |
| `[fonts-browser] catalog` | Font library | text | `https://paperpaw.org/api/v1/fonts.json` | Where the list of fonts to download comes from: the address of a fonts.json. |
| `[store] catalog` | Plugin library | text | `https://paperpaw.org/api/v1/plugins.json` | Where the list of plugins to install comes from: the address of a plugins.json. |
| `[diagnostics] pages` | Test pages | 1 to 10000 | `20` | Pages of the display test screen. |
| `[update] server` | Update server | text | `https://paperpaw.org` | Where PaperPaw asks for updates: paperpaw.org or a server of your own. |
