| Setting | Name | Values | Default | What it does |
|---|---|---|---|---|
| `[core] library-folder` | Library folder | text | `books` | The folder with your books. |
| `[files] archive` | Archive folder | text | `books/Archive` | Where “Move to the archive” puts finished books. |
| `[files] view` | View | `files.view.list`, `files.view.covers` | `files.view.list` | A list with covers and how far each book is read, or a grid of large covers. |
| `[files] covers` | Covers | `files.covers.mono`, `files.covers.gray` | `files.covers.mono` | Gray is finer, black and white responds faster. |
| `[files] sort` | Sort by | `files.sort.recent`, `files.sort.name` | `files.sort.recent` | How the library sorts books: those read last first, or by title. |
| `[calibre] address` | Address | text | `` | Only if Calibre is not found: the address of its computer. |
| `[file-manager] hidden` | Hidden files | `true`, `false` | `false` | Files and folders starting with a dot, e.g. PaperPaw's own data. |
| `[opds] covers` | Catalog covers | `true`, `false` | `true` | Pictures of the books in the lists of catalogs, on devices with the memory for them. |
| `[opds] sync-limit` | Books per sync | 10 to 1000 | `50` | The most books a catalog gets in one sync. |
| `[news] articles` | Articles a feed | 5 to 200 | `30` | How many of a feed's newest articles its book holds. |
